# ML Churn Service

Сервис для предсказания оттока клиентов на FastAPI.

3. Создать объект приложения `app = FastAPI()` — сделано
4. Добавить эндпоинт `GET /`, который возвращает `{"message": "ml churn service is running"}` — сделано

4. В документации `/docs` описать пример запроса и ответа для эндпоинта `/predict` — сделано

   За основу взят типичный клиент: тариф 29.99, 20.5 часов использования, 1 обращение в поддержку, 12 месяцев с сервисом, без неуспешных платежей, europe, mobile, card, автоплатёж включён. В остальных профилях изменены только указанные признаки.

   - тариф, число обращений в поддержку, регион и устройство почти не влияют;
   - модель редко предсказывает класс 1: порог 0.5 проходит только около 2% клиентов датасета, хотя уходят 20%, поэтому f1 низкий;
